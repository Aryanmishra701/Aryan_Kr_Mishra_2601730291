# Portfolio deliverables

## Resume PDF
A one-page draft resume PDF is included as `resume.pdf`. Add your real email, phone, degree/program, expected graduation year, and any verified coursework before submission. Remove any skills that you cannot demonstrate.

## Learning roadmap
`learning_roadmap.md` is personalised for a DevOps specialisation. Update it as your skills and interests develop.

## GitHub and LinkedIn profile evidence
- Complete GitHub profile photo, bio, and at least two skills.
- Create a profile README repository named exactly `Aryanmishra701`, with a skills table and project links.
- Pin `DeveloperPortfolio` on your GitHub profile.
- Update LinkedIn with a professional photo, headline, education, at least two skills, and DeveloperPortfolio as a project with its GitHub link.
- Capture your own screenshots as `Screenshots/github_profile.png` and `Screenshots/linkedin_profile.png`.

Commit the resume and roadmap:
```bash
git add Portfolio/
git commit -m "docs: add technical resume and personalised learning roadmap"
```

Commit profile screenshots separately:
```bash
git add Screenshots/
git commit -m "docs: add GitHub and LinkedIn profile screenshots"
```
